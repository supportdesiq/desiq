# DESIQ Category Expansion V1

## What changed
- Expanded the DESIQ learning-world catalogue from 7 to 10.
- Added Games & Game Design (`/subjects/games`).
- Added Stitching & Embroidery (`/subjects/stitching-embroidery`).
- Added Cooking & Food Skills (`/subjects/cooking`).
- Added starter learning topics, sample challenge prompts and tool/experience outlines for each new world.
- Updated homepage hero copy, hero collage, learning-world count, section heading, pricing-plan feature wording and site metadata to say ten worlds.
- Updated generic subject-page wording so it does not imply a live cost estimator exists in every category.
- No database migration is included or required for these static category pages.

## Important scope note
These are category discovery/introductory pages and sample challenge outlines. Dedicated instructor content, full lesson libraries, interactive challenge engines, submissions, certificates and category-specific admin workflows still need to be built before those features can be advertised as live for the new categories.

## Existing areas
Existing Architecture, IT Support, Hardware, Coding + AI, Sustainability, Languages and Drawing & Art routes/data are retained. No Supabase schema or environment variable changes are included.
