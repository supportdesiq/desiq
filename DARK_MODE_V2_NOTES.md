# DESIQ Dark Mode Refinement V2

This update expands dark-theme styling across the main site, Architecture learning and professional studio pages, and IT Support pages.

## What changed
- Added dark-only surface, typography, border, form and utility-class overrides.
- Improved Architecture challenge library, challenge briefs, builder panels, discovery notes, quantity tables and professional controls.
- Improved IT Support landing, categories, challenge library, runner, practical activities, tickets, dashboard, Skill Passport and admin interfaces.
- Kept drafting canvases and blueprint drawing surfaces light for legibility and accurate visual work.
- Kept the existing light theme declarations unchanged.

## Deployment
1. Back up your current project folder.
2. Copy the contents of `desiq-repo` into your existing local repository, replacing files when prompted.
3. Do not replace or upload `.env.local`.
4. Run `npm run dev` and test light and dark modes across the homepage, Architecture and IT Support.
5. Commit and push only after visual verification.

This is a CSS-only refinement. A full production build has not been run in this environment.
